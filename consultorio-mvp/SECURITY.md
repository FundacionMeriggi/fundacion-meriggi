# Seguridad

Este repositorio contiene un MVP y no debe utilizarse todavía con datos clínicos reales.

## Información sensible

No crear issues, commits o capturas que incluyan:

- Datos identificatorios de pacientes.
- Historias clínicas o evoluciones.
- Contraseñas, tokens o API keys.
- Claves de Supabase o Resend.
- Respaldos exportados desde la aplicación.

## Reporte de problemas

Los problemas de seguridad deben comunicarse de manera privada al responsable técnico de Fundación Meriggi y no publicarse en issues abiertos.
